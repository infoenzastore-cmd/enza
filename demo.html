LOCAL TESTNET MODE

Verify settlement on-chain.
Then confirm here.

When run with the local API or the deployed Netlify functions, the backend verifies the Testnet transaction status, the on-chain order amount, payer and expiry on the deployed checkout contract before an order becomes paid. A demo experience ticket appears only after that check succeeds. The browser detects its mode from /api/config: a deployed serverless backend runs the real Testnet flow; a purely static host (GitHub Pages or a Netlify deploy without functions) stays in the labelled paymentless preview and never presents a simulated purchase as payment.

No live product fulfillment, venue capacity, Axess.Zone integration or vendor payout is implemented in this checkout.
